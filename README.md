# Case Management Workbench (prototype)

A clickable prototype for a product case study. It redesigns the daily
workflow of an RN case manager at a health plan, so less time goes to
searching, reconciling and documenting, and more to patient conversations.

Live demo: [https://Priya-Y7.github.io/HiLabs-Product-Caselet/](https://priya-y7.github.io/HiLabs-Product-Caselet/)

## What it shows
- Work Queue: members ranked by urgency, with the reason and next action
- Member 360: timeline, medication conflicts across sources, data freshness, care gaps
- Outreach & Docs: contact history, best time and channel, AI-drafted note for approval, follow-up tasks
- Care Journey: one member's path through the workbench
- Pilot Metrics: MVP scope, success metrics, pilot plan and risks
- Task Tracker and Export (copy or PDF)

## Notes
- All patient data is fictional and was created for this case.
- AI outputs (summaries, note drafts) are pre-written to simulate the feature.
  Clinicians confirm medication and care decisions.
- Time-saving figures are illustrative assumptions, not measured results.
- Single-file HTML app with no build step.
